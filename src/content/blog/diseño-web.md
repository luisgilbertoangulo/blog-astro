# La importancia del diseño web

El diseño web es fundamental para
transmitir confianza y profesionalidad.

## Algunos aspectos importantes

- Diseño adaptable a móviles.
- Buena organización de contenidos.
- Tipografía legible.
- Navegación sencilla.
- Velocidad de carga.

## Una buena experiencia

Una web no debe ser solamente bonita.
También debe ser fácil de utilizar.
