# ¿Qué es el desarrollo web?

El desarrollo web es el proceso de crear
sitios y aplicaciones que funcionan en Internet.

## Las tecnologías fundamentales

Podemos destacar tres tecnologías:

- HTML: estructura de la página.
- CSS: diseño y presentación.
- JavaScript: comportamiento e interactividad.

## Conclusión

El desarrollo web combina diferentes
tecnologías para crear experiencias digitales.
